# idc-AquaNetProject
El proyecto consiste en un sistema IoT completo de riego automático para una zona alejada, abarcando desde la adquisición de datos hasta su visualización en la nube. Se basará en una Raspberry Pico W equipada con comunicación LoRa para controlar una electroválvula.

## Ramas Proyecto
El proyecto contiene dos ramas:
- main
- dev
Se trabajará en la rama dev, realizando push a main cuando tengamos versiones estables.
